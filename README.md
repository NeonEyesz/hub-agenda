# hub-agenda

Aplicativo OAuth 2.0 de uso pessoal para acesso programático à Google Calendar API.

Não é distribuído e não é oferecido a terceiros. Existe para que os agentes de IA do meu
próprio computador possam ler e criar eventos na minha agenda, com a minha autorização.

- Escopo solicitado: https://www.googleapis.com/auth/calendar
- Uso: pessoal, uma única conta (a do titular)
- Política de privacidade: [PRIVACIDADE.md](PRIVACIDADE.md)
